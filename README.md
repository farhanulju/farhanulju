## How I work

- **On merchant calls every week.** Syncs, live demos on their real catalog data, and training their store staff. The transcripts feed the backlog directly.
- **Confirm the need before scoping.** When a merchant asked for an accounting sync, we confirmed on a call what they actually needed before building anything, then drew one clear line: Shopify owns inventory, QuickBooks owns money.
- **Let the data pick the next fix.** When PostHog showed CubeNation's mobile pages shifting as they loaded, Core Web Vitals jumped the queue ahead of new features.
- **Ship fast, but not at any cost.** I build with AI coding agents every day, and our engineers test their own features with Claude. When that speed started causing regressions, we put logging and bug fixes ahead of new features for a sprint.
